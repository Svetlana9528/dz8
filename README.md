# Домашнее задание к работе 8
Условие: 20) Вычислите вещественное значение 1 + 1/2 + 1/3 + … + 1/N для целого N, заданного пользователем

# Алгоритм и блок-схема:
Алгоритм:
1. Начало.
2. Ввод пользователем целого числа N с клавиатуры.
3. Обнуление вещественной суммы: S = 0.0.
4. Запуск цикла с параметром i от 1 до N с шагом 1.
5. Вычисление текущего шага внутри цикла: S = S + 1.0 / i.
6. Повторение действий 4–5, пока выполняется условие i <= N.
7. Вывод итогового вещественного значения S на экран.
8. Конец.

# Код

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

int main() {
    setlocale(LC_ALL, ".UTF8");
    int N;
    double S = 0.0; // Инициализация вещественной суммы ряда

    printf("Введите целое число N: ");
    scanf("%d", &N);

    for (int i = 1; i <= N; i++) {
        S += 1.0 / i;
    }

    printf("Вещественное значение суммы ряда: %.6f\n", S);
    return 0;
}
```
